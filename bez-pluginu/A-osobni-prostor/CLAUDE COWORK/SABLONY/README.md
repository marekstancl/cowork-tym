# SABLONY

Globální opakovatelné formáty, použitelné napříč projekty bez úprav.

| Šablona je... | Ulož do |
|---|---|
| Univerzální, bez brandu (`tydenni-report.md`, `meeting-notes.md`) | `SABLONY/` |
| Brandová, v tónu konkrétního projektu (smlouva firmy, post za firmu) | `projects/<projekt>/workshop/templates/<kategorie>/` |

Kategorie lokálních šablon (doporučené, můžeš přidat vlastní): `legal/`, `communication/`, `marketing/`, `client/`, `personal/`.

**Založení:** „Ulož to jako šablonu do SABLONY/. Strukturu zachovej, obsah smaž."
**Použití:** „Použij šablonu X."

Tipy na první šablony: `tydenni-report.md`, `meeting-notes.md`, `klientska-nabidka.md`, `workshop-agenda.md`.
