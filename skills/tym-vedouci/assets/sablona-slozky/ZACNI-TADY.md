# Začni tady

Vítej v týmovém prostoru **{TYM}**. Pracuje se přes Claude **Cowork** - AI agent ti pomáhá s prací nad soubory v téhle složce.

Nemusíš nic umět dopředu. Postup je v `instrukce/ONBOARDING-clen.md`:

1. Udělej kroky **A1-A5** z návodu (účet, soukromí, disk, plugin). Ty agent udělat nemůže.
2. Pak v Coworku napiš: **„Jsem nový člen týmu, proveď mě nastavením.“** Agent tě provede zbytkem (projekt, instrukce, testy).

Počítej zhruba s hodinou.

Když si nevíš rady, napiš vedoucímu ({VEDOUCI}).
