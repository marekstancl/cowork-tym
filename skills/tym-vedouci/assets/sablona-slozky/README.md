# Sdílená složka - {TYM}

Sdílený pracovní prostor týmu. Leží na cloudovém disku, synchronizuje se na počítače všech členů.

**Poprvé tady? Otevři `ZACNI-TADY.md`.**

| Co | Obsah | Kdo píše |
|---|---|---|
| `PRAVIDLA-VERZE.txt` | verze pravidel + historie, čtou ji hooky | vedoucí |
| `PRAVIDLA.md` | závazná pravidla práce | vedoucí |
| `instrukce/` | onboarding, jak pracovat s agentem, projektové instrukce člena | vedoucí, ostatní navrhují |
| `sablony/` | šablony dokumentů, jediná verze | vedoucí |
| `kb/` | znalostní báze, rejstřík `INDEX.md` | agenti podle pravidel |
| `lide/` | jména a pracovní kontakty | všichni |
| `vedouci/` | výstupy vedoucího pro tým | vedoucí |
| `clen-<jméno>/` | celý pracovní adresář člena | člen |

**Kritické:** složka musí být v klientovi disku nastavená jako **offline / zrcadlená**, ne stream. Jinak ji Cowork vidí prázdnou (ikona mráčku u souborů = špatně).

**Konflikty:** jeden soubor upravuje v jednu chvíli jeden člověk. Duplikáty `soubor (1).md` se slučují ručně.
